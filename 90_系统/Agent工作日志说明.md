# Agent 工作日志

本库面向 Agent 使用，Obsidian 的日记功能用于记录 Agent 的实际工作，不承载用户个人日记。工作日志与每日变更记录共用同一篇笔记，不建立第二套日志。

## 配置与入口

| 项目 | 当前设置 |
|---|---|
| 插件 | 已启用 Obsidian 核心插件 Daily Notes 与 Templates |
| 每日目录 | `90_系统/变更记录/` |
| 文件名 | `YYYY-MM-DD.md`，一天一篇 |
| 模板 | [[90_系统/模板/每日笔记模板]]，同时供 Daily Notes 与 Agent 使用 |
| 索引 | [[90_系统/变更记录]]，只维护日期链接与一句当日范围 |
| 时间约定 | UTC+08:00；设备日期与时间不在该时区时，须核对模板生成值 |

在 Obsidian 命令面板执行“打开/创建今天的日记”，当天笔记已存在时直接打开，不再创建另一篇，也不向已有笔记重复插入整份模板。若 Obsidian 已打开，重新打开本库后核对新的日记目录设置。

Agent 不依赖桌面插件才能写入：按同一目录和文件名读写即可。当天文件不存在时按模板建立，已存在时只新增本次条目。具体写入、时间和变更联动规则见 [[AGENT]]。

插件只负责按日期打开或创建文件，不会自动运行 Agent，也不会自动把聊天写成日志。

## 记录什么

- 正文、路径、规则、配置或代码的实质更改，按一个任务批次记一条，可覆盖多份文件；保留结果、相关路径与必要验证。
- 知识、决定或任务已经写入正式笔记时，只留下变更摘要与链接，不复制正文或整套任务状态。
- 无实质更改的答疑或检查默认不记，用户要求保存结果时除外；仅更新会话摘要及其入口不触发日志，必要接续信息由摘要承接。
- 日志索引仅在新增日期或当日范围明显变化时维护，不逐条镜像日记录。

不逐条复制工具调用或完整会话，不记录用户私人日记、敏感原文或凭据；用户明确要求全程只读时，不为留日志额外写文件。

## 如何用于接续

继续任务时，先核对对应项目或领域与已有摘要；需要追溯时，再从日志索引查相关日期。旧日志是历史证据，不自动成为现行规则。

日志保留“当时做了什么”，知识与行动先归对应项目、领域或资源；不能用记日志替代正式归位。会话仅保留必要的接续线索，最小记录规则见 [[AGENT#会话记录]]。
