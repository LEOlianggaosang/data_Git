# 收集箱

这里临时收集尚未判断用途或归属的想法、链接和资料，对应 CODE 的 Capture 阶段。

## 处理方式

1. 先快速记录来源、日期和待处理问题，不在收集时追求完美格式。
2. 定期回顾；按行动归入项目、领域、资源或归档。
3. 归位后更新相关笔记链接，并在需要时更新 [[INDEX]]。

用户要求“等正式提出再处理”的想法，保留在此处并注明启动条件，不随例行回顾自动启动或转出。
