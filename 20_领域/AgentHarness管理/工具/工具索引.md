# 工具索引

本索引覆盖 Copilot 本轮可发现的工具注册表，包括宿主内置工具、工作区/会话工具及扩展或其他集成贡献的工具。注册表会随宿主、权限、配置和会话变化；工具名出现不代表它在所有 Copilot 环境中都可用。MCP Server 的工具另见 [[20_领域/AgentHarness管理/MCP/MCP索引]]。

2026-10-24 快照：21 个直接可见工具、38 个本轮宿主声明的集成工具、GitHub MCP 的 18 个工具；另有 3 个 Mermaid 指令引用的工具未在本轮发现。

## 本会话直接可见的工具

### 仓库、终端与文件

`functions.powershell`、`functions.read_powershell`、`functions.stop_powershell`、`functions.list_powershell`、`functions.view`、`functions.rg`、`functions.glob`、`functions.apply_patch`。

### Web、发现与知识检索

`functions.web_search`、`functions.web_fetch`、`tool_search.tool_search_tool`、`functions.skill`。

### Agent 编排、会话与交互

`functions.task`、`functions.read_agent`、`functions.list_agents`、`functions.write_agent`、`functions.ask_user`、`functions.add_artifact_or_reference`、`multi_tool_use.parallel`。

### 会话数据

`functions.sql`、`functions.session_store_sql`。

上述命名空间来自当前 Copilot SDK 会话的工具定义。不同会话可能没有相同工具；使用时按运行时注册表或工具发现结果确认。
