## Obsidian

在 Obsidian 中以本 Git 仓库根目录打开 vault，不另建嵌套 vault。

保留现有 `.obsidian/`。Templates 与 Daily Notes 已启用，设置如下：

| 项目 | 值 |
|---|---|
| Templates 目录 | `90_系统/模板/` |
| Daily Notes 目录 | `90_系统/变更记录/` |
| 日期格式 | `YYYY-MM-DD` |
| 共用模板 | `90_系统/模板/每日笔记模板` |

配置来源：[Templates](../.obsidian/templates.json)、[Daily Notes](../.obsidian/daily-notes.json)、[核心插件](../.obsidian/core-plugins.json)。

## 变更记录

- Daily Notes 与 Agent 变更记录共用一份日记录，不另建第二套日志。
- 实质变更按任务批次写入 `90_系统/变更记录/YYYY-MM-DD.md`；每天一篇，新条目置顶，时间采用 UTC+08:00。
- 使用 [[90_系统/模板/每日笔记模板]]，只记结果、受影响路径与核验；过程和方法留在所属项目或主题。
- [[DIFF]] 只维护日期链接与一句当日结果；新增日期或当日范围明显变化时才更新，日期倒序、一日一条，不逐项镜像日记录。
- 纯答疑、无实质变更的检查，以及仅维护会话摘要和必要入口，不触发更改记录；引入机制或修改规则、配置仍照常留痕。

## 会话记录

- 仅在用户明确要求“保存会话”“整理接续点”等且有必要接续信息时写入 `90_系统/会话记录/YYYY-MM-DD_HHmm_主题.md`，不因轮末或文件变化自动保存，不预建文件。
- 一会话一篇，文件名取首次建档时间；只保留尚未被主体笔记承接的背景、边界、待决与接续点，已落库内容只链接，不保存完整聊天或敏感原文。
- 语义未变不写文件、不改 `updated`；无法确认会话归属或同路径发生冲突时先确认，不覆盖已有内容。
- 格式与待完成试验见 [[10_项目/会话记录探究与计划/项目总览#记录格式]]；未启用自动 Hook。
