# 收集箱

暂存未处理或归属不明的资料、想法，注明来源与后续动作。

收下、回看与分流使用仓库 Skill [inbox-workflow](../.agents/skills/inbox-workflow/SKILL.md)：主动发现的候选先确认再保存，明确暂存请求直接保存；用户要求整理或相关主题再次讨论时回看，不设定时清空。

明确暂缓的想法注明启动条件；尚不明确的标待确认，未获确认不自动执行。

处理后按 [[PLAN]] 归位，不把收集箱作为长期分类。

## 分类入口

每类使用一个文件夹和一篇同名笔记，具体条目在分类笔记中维护。
