# 本库入口

本仓库称为“智能体库”，同时作为 Obsidian vault，为“个人知识库”的整理维护提供辅助；两库的编辑主体与分工见 [规划中的两库说明](PLAN.md#两库称呼与分工)。本库日记用于 Agent 工作日志，不承载个人日记。本页负责说明从哪里开始，详细内容由下面三个根目录文件分别维护。

## 三个根目录文件的职责

| 文件 | 回答的问题 | 主维护内容 | 不在这里维护 |
|---|---|---|---|
| [PLAN.md](PLAN.md) · 规划 | 为什么建库，按什么方法组织？ | 目标、管理范围、CODE 流程与 PARA 分类原则 | 实际文件清单、项目进度、执行约束 |
| [INDEX.md](INDEX.md) · 导航 | 内容在哪里，从哪里进入？ | 当前目录树、分区入口、项目与主题链接 | 方法定义、规则正文、项目任务状态 |
| [AGENT.md](AGENT.md) · 约束 | 修改时必须遵守什么？ | 归位要求、数据与配置保护、授权边界、变更联动 | 规划说明、目录快照、具体项目方案 |

找资料先看索引，理解组织方式看规划；准备修改时先读约束，再结合规划和索引确认归属与影响。三个文件相互引用，不重复维护同一份目录、规则或任务状态。

工作与更改历史见 [变更记录索引](90_系统/变更记录.md)，由日期链接进入每日的分钟级记录；与 Obsidian 日记共用文件，见 [Agent 工作日志说明](90_系统/Agent工作日志说明.md)。
