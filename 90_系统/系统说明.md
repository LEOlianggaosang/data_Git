# 系统说明

本目录存放模板、库级维护说明、Agent 工作日志、会话摘要与库结构/流程视图，不用于保存主题资料。工作日志按任务批次承载实质变更，不与个人日记混用；会话摘要按需保留接续信息。

## 工作日志

- [[90_系统/变更记录]] — 每日工作与变更链接及概括；详情存放在 `90_系统/变更记录/`，每次记录精确到分钟
- [[90_系统/Agent工作日志说明]] — Daily Notes 的 Agent 用法与接续方式

## 会话记录

全部摘要见 [会话记录目录](会话记录/)；这里只列持续维护的主线，不逐篇登记临时会话与回复切片。有接续信息才建档，同一会话增量更新一篇摘要；规则见 [[AGENT#会话记录]]。

- [[90_系统/会话记录/2026-10-25_2036_知识库探索|2026-10-25 · 知识库探索]] — 派生会话；承接个人知识库的理解、诊断与辅助整理方向。
- [[90_系统/会话记录/2026-10-25_2024_Agent维护|2026-10-25 · Agent 维护]] — 原会话；承接本库文档职责、Agent 工作日志与会话摘要机制。
