# 系统说明

本目录存放模板、库级维护规则、Agent 工作日志与会话摘要，不用于保存主题资料。工作日志同时承载每日变更，不与个人日记混用；会话摘要按会话保留接续信息。

- [[90_系统/变更记录]] — 每日工作与变更链接及概括；详情存放在 `90_系统/变更记录/`，每次记录精确到分钟
- [[90_系统/Agent工作日志说明]] — Daily Notes 的 Agent 用法与接续方式
- [[INDEX#会话记录|会话记录入口]] — `90_系统/会话记录/` 中一会话一篇简短摘要，不是聊天全文备份
- [[90_系统/模板/通用笔记模板]]
- [[90_系统/模板/项目笔记模板]]
- [[90_系统/模板/每日笔记模板]] — Agent 与 Daily Notes 共用的工作日志模板
- [[90_系统/模板/Agent能力条目模板]]

Obsidian Templates 插件的模板目录为 `90_系统/模板/`；Daily Notes 插件使用 `90_系统/变更记录/`、`YYYY-MM-DD` 文件名及每日笔记模板，直接打开或创建同一份工作日志。
