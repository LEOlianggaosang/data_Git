## Obsidian

在 Obsidian 中以本 Git 仓库根目录打开 vault，不另建嵌套 vault。

保留现有 `.obsidian/`。Templates 与 Daily Notes 已启用，设置如下：

| 项目 | 值 |
|---|---|
| Templates 目录 | `90_系统/模板/` |
| Daily Notes 目录 | `90_系统/变更记录/` |
| 日期格式 | `YYYY-MM-DD` |
| 共用模板 | `90_系统/模板/每日笔记模板` |

配置来源：[Templates](../.obsidian/templates.json)、[Daily Notes](../.obsidian/daily-notes.json)、[核心插件](../.obsidian/core-plugins.json)。

## 变更记录

- Daily Notes 与 Agent 变更记录共用一份日记录，不另建第二套日志。
- 实质变更按任务批次写入 `90_系统/变更记录/YYYY-MM-DD.md`；每天一篇，新条目置顶，时间采用 UTC+08:00。
- 使用 [[90_系统/模板/每日笔记模板]]，记录结果、受影响路径、会话来源与核验；过程和方法留在所属项目或主题。
- 每条任务批次按仓库 Skill [session-records](../.github/skills/session-records/SKILL.md#link-changelog) 的流程取得本地身份卡链接；多会话可列多个来源。无法确证时标“待核验”并明确说明，不按日期或作者猜测归属。
- [[DIFF]] 只维护日期链接与一句当日结果；新增日期或当日范围明显变化时才更新，日期倒序、一日一条，不逐项镜像日记录。
- 纯答疑、无实质变更的检查，以及仅维护会话记录和必要引用，不触发更改记录；引入机制或修改规则、配置仍照常留痕。建卡并入原任务，不单独衍生日志。

## 会话记录

- 首版只启用最小身份卡与更改来源联动；首条实际更改需要引用会话时，才在 `90_系统/会话记录/YYYY-MM-DD_HHmm_主题.md` 建档。一会话一篇，文件名取首次建档时间，不因轮末建卡。
- 本地主键与宿主来源分开，字段见 Skill 的[身份卡约定](../.github/skills/session-records/SKILL.md#身份卡)；不以标题认领，不预放空的内容章节，不镜像更改清单。
- 语义未变不写文件、不改 `updated`；身份不可得或发生冲突时明确报告并确认，不覆盖其他会话。
- 回复片段快照、接续恢复、会话内容记录、原始内容记录、可迁移会话数据均只预留接口；对应实现完成且用户明确授权前，不执行内容记录、恢复或导出，不套用旧摘要格式冒充已实现能力，不自动保存完整聊天或敏感原文。
- 当前进度见 [[10_项目/会话记录探究与计划/当前方案]]；[[10_项目/会话记录探究与计划/思路变迁#显式摘要基线|旧格式与试验基线]]只供追溯。未启用自动 Hook。
