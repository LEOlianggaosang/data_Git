# 智能体索引

登记 Copilot 当前可选择或可委托的内置 Agent 类型，以及仓库、用户配置、扩展或组织提供的自定义 Agent。内置运行时 Agent 与 `.agent.md` 自定义定义是两类对象。

## 当前会话可委托的运行时 Agent

下列类型由本会话 Agent 运行时列出；可委托能力受宿主、任务策略与当前会话配置影响。

| Agent 类型 | 能力摘要 | 可用范围 |
|---|---|---|
| `explore` | 只读探索代码库并归纳发现 | 当前运行时 |
| `task` | 执行构建、测试、Lint、安装等命令任务 | 当前运行时 |
| `general-purpose` | 独立实施与调试任务 | 当前运行时 |
| `code-review` | 只读审查改动并报告问题 | 当前运行时 |
| `security-review` | 专项安全审查 | 当前运行时 |
| `research` | GitHub 与 Web 的来源研究 | 当前运行时 |

## 自定义 Agent 文件

本仓库未发现项目级自定义智能体定义（例如 `.github/agents/*.agent.md`）；已检查的 VS Code 内置用户配置档案与 `User\agents` 也未发现定义。根目录 [[AGENT]] 是知识库约束文件，不是自定义智能体定义；当前会话由 Copilot SDK in VS Code 承载，见 [[20_领域/AgentHarness管理/Harnesses/Harnesses索引]]。

本结论仅覆盖已检查路径；其他配置档案、扩展、组织策略或当前会话外的运行时 Agent 仍需单独盘点。新增自定义 Agent 时，将管理记录放在本模块，并按对应 Harness 的约定保存实际定义文件。

| 自定义 Agent | 来源范围 | 状态 | 工具权限 | 定义文件 |
|---|---|---|---|---|

新增或核验条目时遵循 [[20_领域/AgentHarness管理/管理总览]]，并使用 [[90_系统/模板/Agent能力条目模板]]。
