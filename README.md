# Agent 知识库

本库以 Git 仓库根目录为 Obsidian vault；本页说明核心概念、用途、边界与使用方式。

## 概念

| 概念 | 定义 |
|---|---|
| 概念声明 | 本智能体库内的语义约定，作为对象的缩写，避免后续提及的歧义 |
| 登记 | 将某些条目摘录到 [[00_Inbox/个人看板/个人看板]] 中 |
| 根目录文件 | 承担五类库级职责的入口文档，保留必要概念、结构与原则，不展开具体主题正文或操作细则 |
| 正文 | 承载说明、知识、分析、方法与成果的内容本体；收集、项目、领域、资源、归档均为正文承载区，根文件仅保留本职库级正文 |
| 元数据 | 描述文件的类型、状态、日期等属性，通常位于 YAML frontmatter，用于识别、检索与解析，不重复正文结论 |
| 会话记录 | 以最小身份卡关联更改来源，内容记录与接续能力按需逐步扩展，不替代正文或更改记录；机制见 [[90_System/系统说明#会话记录]] |
| 隐藏文件夹 | 点号命名或带隐藏属性的目录及相关隐藏项，如 `.git`、`.obsidian/` |
| 分布式约束 | 核心原则集中在 [[AGENT]]，具体细则就近维护并由入口引用；约束正文如何维护，不承载正文 |
| 智能体自定义（Agent Customization） | 在宿主与运行框架支持的范围内，通过指令、提示词、技能等配置与扩展，调整智能体的行为、工作流和可用能力；不等于训练或修改底层模型，相关模块见 [[20_Areas/智能体管理/模块列表]] |
| 智能体库 / 规则库 | 本库，以 Agent 为主要编辑者，维护知识、方法、规则、工具能力及管理记录，辅助个人知识库的整理维护 |
| 个人知识库 / 灵感库 | 外部个人库（主工作树称 `data_Lgx`），以用户为主要编辑者，持续输入个人内容与灵感，Agent 辅助而不替代输入与判断 |

本表各项声明均属于概念声明。这些概念用于不同维度的定位，并非互斥文件类型；根文件与会话笔记同样可有正文和元数据。

两库分工参考[主工作树定义](https://github.com/LEOlianggaosang/data_Git/blob/8b68c40481db121a1d5cf42818c2a33ba5a78122/PLAN.md#两库称呼与分工)；“规则库”“灵感库”强调侧重，不限定各库只能存规则或灵感。

## 边界

- **用途**：把资料转化为可追溯、可行动、可复用的知识与项目成果。
- **决策**：用户确定目标、授权与关键取舍。
- **范围**：当前工作区的知识、项目、模板及必要工具配置；一仓一 vault。
- **协作**：两库互不替代；未经明确授权不操作其他库，不默认合并或复制个人内容。
